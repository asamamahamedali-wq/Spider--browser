# Open decisions — do not silently assume
1. Final application ID / package namespace approval.
2. Final brand assets, icon and typography.
3. Minimum Android version and supported device matrix.
4. WebView vs alternate browser engine decision.
5. Database choice and retention defaults.
6. Download engine architecture and Android background execution strategy.
7. AI provider/backend, data processing terms, budget and consent model.
8. Whether analytics/crash reporting will exist (default: none until approved).
9. Release signing and distribution strategy.
10. Final free-tier build machine/quota verification.
