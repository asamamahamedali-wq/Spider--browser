# SPIDER BROWSER — حزمة تأسيس المشروع

**الإصدار:** 0.1.0-PH00  
**الحالة:** هيكل Android تجريبي + وثائق تأسيس؛ ليس إصدارًا إنتاجيًا.

## ما تتضمنه الحزمة
- مشروع Android أصلي بسيط باستخدام Kotlin.
- إعداد Gradle وملف Codemagic.
- شاشة إثبات تهيئة فقط.
- وثائق المتطلبات والهندسة والأمان والاختبار والقبول.
- بروموت رئيسي وقواعد تنفيذ ومراجعة.
- سجل قرارات ومراحل المشروع.

## بناء APK
يتطلب البناء بيئة فيها JDK 17 وAndroid SDK/Build Tools 35، واتصالًا لتنزيل Gradle واعتماديات Android عند أول بناء.

على Linux/macOS:
```bash
chmod +x ./gradlew
./gradlew assembleDebug
```
على Windows:
```bat
gradlew.bat assembleDebug
```
الناتج المتوقع:
`app/build/outputs/apk/debug/app-debug.apk`

## البناء على Codemagic
1. ارفع محتويات هذا المجلد إلى مستودع GitHub خاص.
2. اربط المستودع يدويًا بحساب Codemagic.
3. راجع نوع جهاز البناء والرصيد/التكلفة المعروضة قبل تشغيل أي عملية.
4. اختر workflow: `spider-browser-ph00-debug`.
5. لا تفعّل التوقيع أو النشر أو أي خدمة مدفوعة في PH-00.

## حدود مهمة
- لم يتم إنشاء أو ربط أي حساب.
- لم يتم تشغيل Codemagic من هذه الحزمة.
- لم يتم توليد APK داخل هذه الجلسة؛ يلزم تشغيل البناء في بيئة Android فعلية.
- لا يحتوي هذا الهيكل على متصفح أو مدير تنزيلات مكتمل؛ إنه نقطة انطلاق قابلة للبناء لاختبار مسار APK.
- لا تستخدم مفاتيح API داخل المصدر أو APK. لا ترفع كلمات مرور أو ملفات توقيع للمستودع.
- لا تضف صلاحيات Android قبل وجود ميزة محددة ومراجعة سبب الحاجة إليها.
