# ملفات إصلاح تأسيس SPIDER BROWSER — PH-00

هذه الحزمة تعالج اختلاف بنية Android الذي ظهر في فحص مستودع GitHub.

## الملفات داخل الحزمة

- `build.gradle.kts` — **استبدال** ملف الجذر الحالي؛ الملف الموجود حاليًا يحتوي إعدادات تطبيق Android بدل إعدادات الجذر.
- `app/build.gradle.kts` — إنشاء إعدادات وحدة التطبيق.
- `app/src/main/AndroidManifest.xml` — إنشاء Manifest داخل مسار Android القياسي.
- `app/src/main/java/com/osama/spiderbrowser/MainActivity.kt` — نقل/إضافة شاشة الاختبار الأولية.
- `app/src/main/res/values/styles.xml` — تعريف المظهر الذي يشير إليه Manifest.
- `app/proguard-rules.pro` — قواعد ProGuard الخاصة بوحدة التطبيق.
- `codemagic.yaml` — **استبدال اختياري موصى به** ليتحقق من المسارات الصحيحة قبل البناء.

## طريقة الإضافة إلى GitHub

1. نزّل ملف ZIP وافتحه/استخرج محتوياته على جهازك.
2. افتح مستودع `Spider--browser` في GitHub.
3. استخدم **Add file → Upload files**.
4. ارفع محتويات المجلد المستخرج مع الحفاظ على المسارات كما هي.
5. عند سؤال GitHub عن التعارض، استبدل `build.gradle.kts` الموجود في جذر المستودع و`codemagic.yaml` فقط بالنسختين الموجودتين هنا.
6. لا تحذف ملفات الوثائق الموجودة.
7. تأكد أن الملفات الجديدة تظهر في المسارات نفسها المكتوبة أعلاه، ثم نفّذ Commit.

## ملاحظات مهمة

- هذه حزمة ملفات تأسيس/إصلاح فقط، وليست APK.
- لم يتم تشغيل Gradle أو إثبات نجاح البناء بعد.
- ملف `gradlew` الموجود أصلًا في المستودع هو سكربت bootstrap مخصص يقوم بتنزيل Gradle 8.9؛ لذلك لا تتضمن هذه الحزمة `gradle-wrapper.jar`.
- إعدادات Android Gradle Plugin 8.7.3 وGradle 8.9 وJDK 17 متوافقة وفق جدول Android Developers. راجع التوافق قبل أي ترقية مستقبلية.
- ملف Codemagic يستخدم `mac_mini_m2` كما في إعداد المستودع الحالي؛ لا تشغّل البناء قبل التأكد من أن نوع الجهاز والدقائق متاحة ضمن خطتك دون تكلفة.
- لا توجد في هذه الحزمة مفاتيح API أو كلمات مرور أو بيانات توقيع.

## بعد الرفع

أرسل لي رابط المستودع أو لقطة لقائمة الملفات. سنراجع المسارات أولًا، ثم نتحقق من Codemagic وخطة الاستخدام قبل تشغيل أي بناء.
