# SPIDER BROWSER — PH-00 files

1. فك ضغط الحزمة.
2. ارفع مجلد `app` إلى جذر مستودع GitHub مع الحفاظ على المسارات.
3. استبدل `build.gradle.kts` الموجود في جذر المستودع بالنسخة الموجودة هنا.
4. لا تستبدل `codemagic.yaml` إذا كانت النسخة الموجودة في المستودع هي النسخة المحدّثة.
5. لا تحذف ملفات التوثيق أو الملفات الحالية الأخرى.

لم يتم تشغيل بناء سحابي أو إنشاء APK بهذه الحزمة. قبل تشغيل Codemagic، تحقق من خطة الاستخدام والتكلفة وأي طلب ترقية أو فوترة. توقف ولا توافق على أي تكلفة دون موافقة صريحة.
